# 🌐 PRODIGY_WD_01 – Responsive Landing Page

> Task 01 of my Web Development Internship at **Prodigy InfoTech**

A modern, fully responsive landing page built using **HTML**, **CSS**, and **JavaScript**. The project features an interactive navigation menu that changes its appearance when the page is scrolled or when users hover over navigation items, providing a smooth and engaging user experience.
